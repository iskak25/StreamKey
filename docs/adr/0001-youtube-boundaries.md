# ADR-0001: Границы защиты и допустимость использования YouTube

Статус: открыт. Production-просмотр закрыт (`YOUTUBE_PLAYBACK_ENABLED=false`).

## Решение
- Приложение защищает только собственную страницу и выдачу параметров плеера; это не DRM.
- Video ID виден авторизованному зрителю; Unlisted-ссылка остаётся пригодной вне приложения.
- Используются только официальные параметры IFrame API: без масок, обрезки iframe и проксирования потока.

## Условие запуска
Владелец продукта документирует проверку применимости правил YouTube (ТЗ п. 2.2) к механике одноразовых приглашений. До этого работает только mock-плеер.

## Проверка
Протокол проверки на реальных устройствах (этап 0) прикладывается к этому ADR.
