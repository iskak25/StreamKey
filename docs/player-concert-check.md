# Проверка плеера перед концертом

Дата: 31 октября 2026 года.

Локальная production-сборка `npm run build` прошла. `npm run typecheck` прошёл.
`npm test`: 23 теста прошли, включая 3 теста адаптера плеера с подменённым YouTube API.
Это не подтверждает реальное воспроизведение, Firebase E2E или работу мобильных устройств.

## Параметры и ограничения

Используются controls=0, disablekb=1, fs=0, playsinline=1, enablejsapi=1, rel=0,
autoplay=0 и origin приложения. Собственная кнопка вызывает playVideo/pauseVideo.
Полноэкранная кнопка YouTube отключена намеренно через fs=0. Собственная кнопка разворачивает
контейнер через браузерный Fullscreen API и показывается только при document.fullscreenEnabled.
Страница зрителя занимает окно целиком; Play/Pause расположен под видео, без перекрытия iframe.
На странице зрителя нет собственных кнопок передачи исходного URL. Индивидуальные приглашения
в кабинете организатора остаются без изменений.

Официальные параметры не гарантируют скрытие названия, канала, брендинга, кнопок
«Поделиться», «Смотреть позже» и перехода на YouTube. rel=0 не отключает рекомендации.
Нет CSS-масок, перекрытий или обрезки iframe. Исходная ссылка может быть извлечена.
На ширинах менее 356px минимальная высота YouTube 200px имеет приоритет над точным 16:9.

## Обязательная репетиция на реальном эфире

Все пункты ниже пока НЕ ПОДТВЕРЖДЕНЫ. Выполнять на согласованной тестовой трансляции,
с отдельными тестовыми приглашениями, сохраняя production cookies зрителей.

| Проверка | Ожидаемый результат |
| --- | --- |
| Chrome desktop, Chrome Android, Safari iPhone | Реальное изображение и звук, ручной Play, Pause и повторный Play |
| Наведение, касание, пауза, завершение | Записать фактически видимые элементы YouTube; не обещать их отсутствие |
| Поворот телефона и узкий экран | Видео не обрезано, кнопка доступна, нет горизонтального скролла |
| Полноэкранный режим | Собственная кнопка раскрывает контейнер, повторное нажатие/Escape возвращает страницу; на неподдерживаемом устройстве кнопка отсутствует |
| Обновление страницы | Тот же браузер сохраняет доступ; при необходимости повторный Play |
| Повторное открытие приглашения | Прежний браузер с сохранённой cookie получает прежнюю сессию |
| Другой браузер/устройство | Та же активированная ссылка получает отказ |
| Отзыв тестового приглашения | Плеер удаляется после отказа API или окончания lease; повторный вход запрещён |
| Потеря сети более 90 секунд | По окончании lease iframe удаляется, появляется сообщение восстановления |
| Возврат сети | Доступ заново подтверждается сервером, плеер загружается, Play работает |
| Недоступный источник/запрет embed | Понятная ошибка и кнопка повторной загрузки |

У одного браузера могут быть несколько вкладок: текущая модель привязана к браузерной
сессии, не к эксклюзивному окну. Backend, приглашения и модель сессий не изменялись.

До подтверждения репетиции готовность к концерту не установлена.
